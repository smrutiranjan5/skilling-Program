## Features Implemented

### Book Details

- Displayed list of books using `map()`.
- Used React Keys.

### Blog Details

- Displayed blog title.
- Displayed author.
- Displayed description.

### Course Details

- Displayed course names.
- Displayed course dates.

### React Concepts Used

- Conditional Rendering
