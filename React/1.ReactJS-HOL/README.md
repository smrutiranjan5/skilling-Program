# React Exercise 1 - My First React Application

## Objective

- Create a React application using Create React App.
- Display a welcome message using React.
- Learn the basic React project structure.

## Technologies Used

- React
- JavaScript
- Node.js
- npm
- Visual Studio Code

## Project Structure

```
1.ReactJS-HOL
│
├── myfirstreact
├── README.md
└── Screenshots
```

## Steps Performed

1. Installed Node.js and npm.
2. Created a React application using:

```
npx create-react-app myfirstreact
```

3. Opened the project in Visual Studio Code.
4. Modified `App.js`.
5. Displayed:

```
Welcome to the first session of React
```

6. Executed the project using:

```
npm start
```

## Output

The application successfully displays:

**Welcome to the first session of React**
