# React Exercise 2 - Student Management Portal

## Objective

- Create a React application named StudentApp.
- Create multiple React class components.
- Render multiple components in a single application.
- Understand component-based architecture in React.

## Technologies Used

- React
- JavaScript (ES6)
- Node.js
- npm
- Visual Studio Code

## Steps Performed

1. Created a React project using:

```
npx create-react-app studentapp
```

2. Created a folder named **Components** inside the **src** folder.

3. Created the following class components:

- Home.js
- About.js
- Contact.js

4. Imported all components into **App.js**.

5. Rendered all components in the application.

6. Executed the project using:

```
npm start
```

7. Verified the output in the browser.

## Output

The application successfully displays the following messages:

- Welcome to the Home page of Student Management Portal
- Welcome to the About page of the Student Management Portal
- Welcome to the Contact page of the Student Management Portal

## Learning Outcome

- Learned how to create React class components.
- Learned how to organize components inside the src folder.
- Learned how to import and render multiple components.
- Understood the basics of component-based development in React.
