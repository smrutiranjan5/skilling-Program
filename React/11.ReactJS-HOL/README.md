# React Exercise 11 - Event Handling in React

## Objective

This exercise demonstrates Event Handling in React.

The following concepts are implemented:

- Event Handling
- Synthetic Events
- Multiple Event Methods
- Passing Arguments to Event Handlers
- Counter Application
- Currency Converter

## Features Implemented

### Counter

- Increment Button
- Decrement Button
- Multiple Function Calls

### Welcome Button

- Displays Welcome message using function arguments.

### Synthetic Event

- Displays "I was clicked".

### Currency Converter

- Accepts Amount.
- Converts Amount on Submit.
