# React Exercise 10 - Office Space Rental App using JSX

## Objective

This exercise demonstrates the use of JSX in React applications.

The following concepts are implemented:

- JSX Syntax
- JavaScript Expressions in JSX
- Rendering JSX to DOM
- Inline CSS Styling
- Rendering List of Objects using map()

## Features Implemented

### 1. JSX

- Used JSX syntax to create React elements.
- Rendered JSX elements to the browser.

### 2. Office Details

- Created an object containing:
  - Office Name
  - Rent
  - Address
  - Office Image

### 3. List of Offices

- Created multiple office objects.
- Displayed them dynamically using the `map()` function.

### 4. Inline CSS

- Applied inline styling to the Rent field.
- Rent is displayed:
  - **Red** when Rent is less than or equal to ₹60000.
  - **Green** when Rent is greater than ₹60000.

### 5. Image Rendering

- Displayed the office image using the `<img>` tag.
