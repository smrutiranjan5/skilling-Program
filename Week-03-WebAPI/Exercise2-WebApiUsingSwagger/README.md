# Web API using .NET Core with Swagger

##  Objective
This project demonstrates the creation of a simple ASP.NET Core Web API and integration of Swagger for API documentation and testing.

##  Technologies Used
- ASP.NET Core Web API
- .NET 10
- Swagger (Swashbuckle.AspNetCore)
- Visual Studio 2022

##  Project Structure

```
FirstWebApi
│── Controllers
│   ├── ValuesController.cs
│   └── WeatherForecastController.cs
│── Program.cs
│── appsettings.json
│── launchSettings.json
│── FirstWebApi.http
```

##  Features
- Created a basic ASP.NET Core Web API.
- Implemented GET, POST, PUT and DELETE endpoints.
- Configured Swagger for API documentation.
- Tested API endpoints using Swagger UI.
- Demonstrated RESTful API development.

##  How to Run

1. Clone the repository.
2. Open the solution in Visual Studio 2022.
3. Restore NuGet packages.
4. Run the project.
5. Open Swagger UI from the browser.

##  Output

- Swagger UI displaying API endpoints.
- Successful execution of GET requests.
- JSON responses returned from the API.

## Learning Outcomes

- Learned the basics of ASP.NET Core Web API.
- Understood routing and controller creation.
- Integrated Swagger for API documentation.
- Explored REST API testing using Swagger.
