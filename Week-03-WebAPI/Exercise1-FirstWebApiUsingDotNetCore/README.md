# Exercise 1 - First Web API using .NET Core

## Objective
Create a simple ASP.NET Core Web API project using the API template and understand the basic structure of a Web API.

## Technologies Used
- ASP.NET Core Web API
- .NET
- Swagger UI

## Features
- Created a new ASP.NET Core Web API project.
- Generated ValuesController with CRUD action methods.
- Tested GET endpoint using Swagger UI.
- Verified successful execution of the WeatherForecast API.

## API Endpoints

| Method | Endpoint |
|---------|----------|
| GET | /api/Values |
| GET | /api/Values/{id} |
| POST | /api/Values |
| PUT | /api/Values/{id} |
| DELETE | /api/Values/{id} |
| GET | /WeatherForecast |

## Output
The API was successfully executed using Swagger UI.
